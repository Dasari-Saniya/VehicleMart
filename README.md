# VehicleMart 🚗🛵🚙

VehicleMart is a modern and responsive web project designed for **buying and selling second-hand vehicles**.  
It demonstrates a clean layout, Bootstrap-powered components, and custom CSS for a professional look.

---

## 🔑 Features
- Responsive **Bootstrap Navbar** with smooth navigation  
- Hero section with **image slider** and overlay text  
- **About Us** section with tabs (Idea, Mission, Vision)  
- **Services** section displaying key offerings  
- **Our Projects** section showing available vehicle categories  
- **Contact Form** with embedded map  
- **Modern Footer** with links, categories, and contact info  

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3**  
- **Bootstrap 5**  
- **JavaScript (Carousel controls)**

---

##📝 Notes
- This project is created for **academic and portfolio purposes**.  
- The vehicle categories, services, and brand images are placeholders — you can replace them with real content.  
- The design is kept **minimal, responsive, and professional** to fit modern web standards.  
- Works on **all devices**: desktop, tablet, and mobile.
